实验代码公开在 GitHub 组织
[lec-algorithm](https://github.com/lec-algorithm)。

课堂示例不需要复制。直接在仓库中创建 Codespace，或者克隆后用 `git pull`
获取新主题。

```sh
git clone https://github.com/lec-algorithm/algorithm-code.git
cd algorithm-code
docker compose up -d
```

作业与个人项目请从 `algorithm-env` 开始：在那里点击 **Use this template**
创建自己的仓库。

本课程要求安装的只有 Git 和 Docker 两样，若使用 Codespaces 则连这两样也不需要，
只要有账号即可。

**个人项目必须以 GitHub 仓库提交。** 请在学期初创建账号并设置 `user.name` 与
`user.email`。提交记录就是工作记录，边做边提交比最后一次性推送更能说明过程。

提交规范会另行公告。
