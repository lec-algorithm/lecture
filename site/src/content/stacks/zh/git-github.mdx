实验代码公开在 GitHub 组织
[lec-algorithm](https://github.com/lec-algorithm)。

`algorithm-code` 是 template 仓库。点击 **Use this template** 在自己账号下创建
副本，然后在那里工作。

```sh
git clone https://github.com/<你的账号>/my-algorithm-code.git
cd my-algorithm-code
docker compose up -d
```

本课程要求安装的只有 Git 和 Docker 两样，若使用 Codespaces 则连这两样也不需要，
只要有账号即可。

**个人项目必须以 GitHub 仓库提交。** 请在学期初创建账号并设置 `user.name` 与
`user.email`。提交记录就是工作记录，边做边提交比最后一次性推送更能说明过程。

提交规范会另行公告。
