每个示例都在 C 实现旁边配一份 Python 实现。两者都是同一份[[pseudo-code|伪代码]]
的转写，连函数名都相同。

```sh
docker compose exec lab bash
python3 selection_sort.py
```

Python 同样在容器镜像中，版本已固定，因此不会在不同人手上表现不同。当前镜像
使用 Python 3.13，且不使用任何外部包。

在 Python 一侧，内存管理由语言代劳，于是只剩下算法流程。把它与 C 版本并排放在
一起，就能看清哪里属于算法、哪里属于语言自身的事务。
