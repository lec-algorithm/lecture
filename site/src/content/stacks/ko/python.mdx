모든 예제에는 C 구현과 나란히 Python 구현이 들어갑니다. 두 구현은 같은
[[pseudo-code|의사코드]]를 옮긴 것이고, 함수 이름도 같습니다.

```sh
docker compose exec lab bash
python3 selection_sort.py
```

Python도 컨테이너 이미지에 들어 있습니다. 버전이 고정되어 있어 사람마다 다르게
도는 일이 없습니다. 현재 이미지는 Python 3.13이고, 외부 패키지는 쓰지 않습니다.

Python 쪽은 메모리 관리를 언어가 대신 해 주므로 알고리즘의 절차만 남습니다.
C 쪽과 나란히 놓고 보면, 어디까지가 알고리즘이고 어디부터가 언어의 사정인지
구분됩니다.
