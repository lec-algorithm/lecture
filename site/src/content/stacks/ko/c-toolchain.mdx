실습 코드의 C 구현은 표준 라이브러리만 씁니다. 외부 의존성이 없으므로 어디서
빌드하든 같은 결과가 나옵니다.

```sh
docker compose exec lab bash
gcc -o selectionSort selectionSort.c && ./selectionSort
```

컴파일러는 컨테이너 이미지에 들어 있습니다. 호스트에 따로 설치할 필요가
없습니다. 현재 이미지의 gcc는 14.2입니다. 디버거(`gdb`)도 함께 들어 있어 포인터가 어디를 가리키는지 직접
들여다볼 수 있습니다.

C를 쓰는 이유는 메모리와 포인터가 코드에 그대로 드러나기 때문입니다. 배열이
어떻게 놓이고 노드가 어디를 가리키는지가 보이지 않으면 자료구조를 이야기하기
어렵습니다.

같은 알고리즘의 [[pseudo-code|의사코드]]와 Python 구현이 같은 폴더에 함께
들어 있습니다.
