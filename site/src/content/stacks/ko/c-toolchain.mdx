실습 코드의 C 구현은 표준 라이브러리만 씁니다. 외부 의존성이 없으므로 컴파일러
하나만 있으면 어디서든 같은 결과가 나옵니다.

- macOS: `xcode-select --install` (clang이 깔립니다)
- Windows: MSYS2의 `mingw-w64-ucrt-x86_64-gcc`
- Linux: `build-essential`

```sh
gcc -o selectionSort selectionSort.c && ./selectionSort
```

C를 쓰는 이유는 메모리와 포인터가 코드에 그대로 드러나기 때문입니다. 배열이
어떻게 놓이고 노드가 어디를 가리키는지가 보이지 않으면 자료구조를 이야기하기
어렵습니다.

준비 방법은 [실습 환경 준비](/article/setup-guide/)에 정리되어 있습니다.
