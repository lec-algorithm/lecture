실습 코드는 GitHub 조직 [lec-algorithm](https://github.com/lec-algorithm)에
공개되어 있습니다. 클론해서 받고, 본인 저장소에서 고쳐 가며 실습합니다.

수업 예제는 복사하지 않습니다. 저장소에서 바로 Codespace를 만들거나 클론해서
`git pull`로 새 주제를 받습니다.

```sh
git clone https://github.com/lec-algorithm/algorithm-code.git
cd algorithm-code
docker compose up -d
```

과제와 개인프로젝트는 `algorithm-env`에서 **Use this template**으로 본인
저장소를 만들어 시작합니다.

수업에서 설치하는 것은 Git과 Docker 둘뿐입니다. 컴파일러와 Python은 컨테이너
안에 들어 있습니다.

**개인프로젝트는 GitHub 저장소 제출이 필수입니다.** 학기 초에 계정을 만들고
`user.name`과 `user.email`을 설정해 두세요. 커밋 기록이 곧 작업 기록이 되므로,
한 번에 몰아서 올리지 말고 진행하면서 남기는 편이 좋습니다.

제출 규격은 별도 공지 글로 올립니다.
