`algorithm-code` 저장소는 컨테이너 하나로 뜹니다. 컴파일러와 Python은 그 안에
들어 있어 따로 설치하지 않습니다.

**GitHub Codespaces로 실습하면 Docker를 설치할 필요도 없습니다.** 저장소의
`.devcontainer/devcontainer.json`이 아래 `compose.yml`의 `lab` 서비스를 그대로
쓰므로, 브라우저에서 열어도 같은 컨테이너입니다. 본인 노트북에서 돌리고 싶을
때만 Docker Desktop이 필요합니다.

```sh
git clone https://github.com/lec-algorithm/algorithm-code.git
cd algorithm-code
docker compose up -d
docker compose exec lab bash
```

셸에 들어가면 그 다음부터는 평소와 같습니다.

```sh
cd src/topic-01-intro-search/01_sequential_search
gcc -o sequentialSearch.out sequentialSearch.c && ./sequentialSearch.out
python3 sequential_search.py
```

`compose.yml`은 `algorithm-code` 저장소 루트에 있습니다. `docker compose`
명령은 전부 그 폴더 안에서 칩니다.

저장소 폴더가 컨테이너의 `/work`에 연결되어 있어, 코드는 호스트의 편집기로
고치고 실행만 컨테이너에서 합니다. 저장하면 바로 반영됩니다.

컨테이너를 쓰는 이유는 환경 차이를 없애기 위해서입니다. C 컴파일러는 운영체제
마다 설치 방법이 다르고 Python은 버전이 갈립니다. 같은 코드가 사람마다 다르게
도는 상황을 만들지 않으려면 실행 환경을 고정하는 편이 낫습니다.

준비 방법은 [실습 환경 준비](/article/setup-guide/)에 정리되어 있습니다.
