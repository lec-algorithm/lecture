Every example carries a Python implementation next to the C one. Both are
transcriptions of the same [[pseudo-code|pseudocode]], down to the function
names.

```sh
docker compose exec lab bash
python3 selection_sort.py
```

Python is in the container image too, at a pinned version, so it does not run
differently for different people. The current image carries Python 3.13, and no
external packages are used.

On the Python side the language handles memory for you, so only the procedure is
left. Put it beside the C version and the line between what is the algorithm and
what is the language's own business becomes visible.
