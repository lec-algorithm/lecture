The C implementations use only the standard library, so they build to the same
result anywhere.

```sh
docker compose exec lab bash
gcc -o selectionSort.out selectionSort.c && ./selectionSort.out
```

The compiler ships in the container image; nothing goes on the host. The image
currently carries gcc 14.2. A debugger (`gdb`) comes with it, so you can look
directly at where a pointer points.

Build to `*.out`. The `.gitignore` filters exactly that, so a Linux binary
compiled in the container never lands in a commit.

C is here because memory and pointers stay visible in the code. If you cannot
see how an array is laid out or where a node points, there is not much to say
about a data structure.

implementation of the same algorithm.
