The practice code is public in the GitHub organization
[lec-algorithm](https://github.com/lec-algorithm).

`algorithm-code` is a template repository. Press **Use this template** to make a
copy under your own account, and work in that.

```sh
git clone https://github.com/<your-account>/my-algorithm-code.git
cd my-algorithm-code
docker compose up -d
```

Git and Docker are the only two things this course asks you to install, and with
Codespaces you do not even need those — only the account.

**The individual project must be submitted as a GitHub repository.** Make your
account early in the semester and set `user.name` and `user.email`. The commit
history is the record of your work, so it reads better made as you go than
pushed all at once at the end.

Submission rules go up as a separate notice.
