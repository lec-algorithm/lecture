#### 높이와 노드 수
::sub[레벨 l에는 노드가 최대 2^l개]

높이가 $$h$$인 full tree는 모든 레벨이 꽉 차 있습니다.

$$
N = 2^0 + 2^1 + \cdots + 2^{h-1} = 2^h - 1
$$

거꾸로 풀면 높이는 노드 수의 로그입니다.

$$
h = \log_2(N + 1) = O(\log N)
$$

<br/>

높이는 **레벨의 수**로 셉니다. 링크 수로 세는 교재와는 1 차이가 납니다.

</Slide>

#### 정의
::sub[모든 노드가 지키는 규칙]

- **왼쪽 서브트리의 모든 키**가 그 노드의 키보다 작습니다.
- **오른쪽 서브트리의 모든 키**가 그 노드의 키보다 큽니다.
- 왼쪽과 오른쪽 서브트리도 각각 이진 탐색 트리입니다.

<br/>

키는 모두 다르다고 둡니다. 같은 값을 다시 넣으면 아무것도 하지 않습니다.

</Slide>

#### 이진 검색과 같은 생각
::sub[주제 01: 가운데와 비교해 절반을 버린다]

- **이진 검색**은 매번 가운데 값과 비교했습니다.
- **이진 탐색 트리**는 그 "가운데"를 미리 루트에 세워 둡니다.
  - 각 서브트리에도 그 부분의 기준값이 서 있습니다.
- 다른 점은 링크로 이어져 있다는 것입니다.
  - 그래서 넣고 빼기가 쉽습니다.

<br/>

**검색이 실패한 자리가 곧 삽입할 자리**입니다. 예제 1에서 그대로 씁니다.

#### 검색 절차
::sub[루트에서 잎 쪽으로 한 길만 내려가므로 O(h)]

```plaintext
ALGORITHM Search(root, key)
    node <- root
    while node != NULL do
        if key = node.key then
            return node                 // 찾았다
        if key < node.key then
            node <- node.left           // 작으면 왼쪽 서브트리만 보면 된다
        else
            node <- node.right          // 크면 오른쪽 서브트리만 보면 된다
    return NULL                         // 비어 있는 자리에 닿았다: 없다
```

</Slide>

#### 노드 데이터와 노드 생성
::sub[새 노드는 자식이 없으므로 두 주소가 NULL입니다]

```c
typedef struct TreeNode {
    int key;
    struct TreeNode *left;   /* 왼쪽 자식의 주소 */
    struct TreeNode *right;  /* 오른쪽 자식의 주소 */
} TreeNode;

TreeNode *createNode(int key) {
    TreeNode *node = (TreeNode *)malloc(sizeof(TreeNode));
    node->key = key;
    node->left = NULL;
    node->right = NULL;
    return node;
}
```

#### 삽입 = 실패한 검색 + 매달기
::sub[이진 탐색 트리 속성을 써서 올바른 위치에 새 항목을 넣습니다]

- 넣을 값을 **찾듯이** 내려갑니다.
  - 작으면 왼쪽, 크면 오른쪽
- **비어 있는 자식 자리**에 닿으면 거기에 새 노드를 답니다.
- 같은 값이 이미 있으면 아무것도 하지 않습니다.

<br/>

이미 있는 노드는 하나도 움직이지 않습니다.  
배열에 끼워 넣을 때처럼 뒤를 밀 필요가 없습니다.

#### 노드가 제자리에 나타나는 이유
::sub[가로 위치가 정렬했을 때의 순번입니다]

- 데모의 노드는 처음부터 자기 자리에 나타납니다.
- 노드를 모두 바닥으로 내려 한 줄에 모으면 이렇게 됩니다.
  - `3 4 5 6 7 8 9 12 20`

#### 삽입 절차
::sub[각 호출은 "이 서브트리에 key를 넣고 그 루트를 돌려준다"는 약속을 지킵니다]

```plaintext
ALGORITHM Insert(root, key)
    if root = NULL then
        return 새 노드(key)             // 검색이 실패한 바로 그 자리
    if key < root.key then
        root.left <- Insert(root.left, key)
    else if key > root.key then
        root.right <- Insert(root.right, key)
    // 같으면 아무것도 하지 않는다 (키는 한 번만 넣는다)
    return root
```

#### 코드로 옮기면
::sub[`01_search_insert/bstSearchInsert.c` · 호출하는 쪽은 돌려받은 루트로 바꿔 둡니다]

```c
TreeNode *insert(TreeNode *root, int key) {
    if (root == NULL) {
        return createNode(key);
    }
    if (key < root->key) {
        root->left = insert(root->left, key);
    } else if (key > root->key) {
        root->right = insert(root->right, key);
    }
    return root;
}

TreeNode *root = NULL;
root = insert(root, 5);       /* 빈 트리면 루트가 NULL에서 새 노드로 바뀐다 */
```

#### 불균형한 트리
::sub[검색 시간이 길어지므로 바람직하지 않습니다]

- 한쪽으로 기운 트리는 **연결 리스트와 같습니다.**
  - 검색이 $$O(n)$$으로 돌아갑니다.
- 정렬된 키 $$n$$개를 넣으면 비교가 $$\dfrac{n(n-1)}{2}$$번입니다.
  - 7개면 21번, 만드는 데만 $$O(n^2)$$
- **레드-블랙 트리**, AVL 트리 같은 균형 트리
  - 넣고 뺄 때마다 모양을 고쳐 높이를 $$O(\log n)$$으로 묶어 둡니다.
  - C++ `std::map`, Java `TreeMap`이 쓰는 것이 이것입니다.

#### 삭제 절차
::sub[경우 1과 경우 2(오른쪽 자식만)가 한 줄로 합쳐집니다]

```plaintext
ALGORITHM Delete(root, key)
    if root = NULL then
        return NULL                         // 지울 값이 없다
    if key < root.key then
        root.left <- Delete(root.left, key)
    else if key > root.key then
        root.right <- Delete(root.right, key)
    else                                    // root가 지울 노드다
        if root.left = NULL then            // 경우 1·2: 자식이 0개이거나 오른쪽 하나
            return root.right
        if root.right = NULL then           // 경우 2: 왼쪽 자식 하나
            return root.left
        succ <- FindMin(root.right)         // 경우 3: 후속자
        root.key <- succ.key                // 후속자의 키를 이 자리에 복사하고
        root.right <- Delete(root.right, succ.key)   // 원래 후속자를 지운다
    return root
```

} else {
    /* 경우 1·2: 자식이 0개이거나 하나 */
    if (root->left == NULL) {
        TreeNode *temp = root->right;   /* free 전에 남길 자식을 받아 둔다 */
        free(root);
        return temp;
    }

        TreeNode *temp = root->left;
        free(root);
        return temp;
    }
    /* 경우 3: 자식이 둘. 후속자를 복사하고 원래 후속자를 지운다. */

}

#### BST와 연결 리스트
::sub[검색·삽입·삭제는 정확히는 모두 O(h)]

| 연산 | BST (균형) | BST (최악) | 정렬된 연결 리스트 |
| --- | --- | --- | --- |
| 생성 | $$O(1)$$ | $$O(1)$$ | $$O(1)$$ |
| 해제 | $$O(n)$$ | $$O(n)$$ | $$O(n)$$ |
| 비었는가·꽉 찼는가 | $$O(1)$$ | $$O(1)$$ | $$O(1)$$ |
| 검색 | $$O(\log n)$$ | $$O(n)$$ | $$O(n)$$ |
| 삽입 | $$O(\log n)$$ | $$O(n)$$ | $$O(n)$$ |
| 삭제 | $$O(\log n)$$ | $$O(n)$$ | $$O(n)$$ |

<br/>

$$O(\log n)$$에는 $$h = O(\log n)$$이라는 가정이 숨어 있습니다. 깨지면 BST도 연결 리스트와 같아집니다.
