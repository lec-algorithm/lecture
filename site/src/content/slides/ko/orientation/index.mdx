## 수업의 방식
::sub[의사코드 한 벌, 구현 두 벌]

- 알고리즘은 **의사코드**로 먼저 정의합니다.
- 같은 것을 **C**와 **Python**으로 구현합니다.
- 언어를 배우는 수업이 아닙니다.
  - 같은 절차가 두 언어에서 어떤 모양이 되는지를 봅니다.
- 실행 환경은 **컨테이너로 고정**합니다.
  - 설치하는 것은 Git과 Docker 둘뿐입니다.
- 강의 50% · 실습 50%
  - 가급적 실습을 많이 진행하려고 합니다.

</Slide>

## 수업 준비물
::sub[설치하는 것은 둘, 만들어 둘 것은 하나]

| 준비물 | 받는 곳 | 확인 |
| --- | --- | --- |
| **Git** | [git-scm.com/downloads](https://git-scm.com/downloads) | `git --version` |
| **Docker Desktop** | [docker.com/get-started](https://www.docker.com/get-started/) | `docker compose version` |
| **GitHub 계정** | [github.com/signup](https://github.com/signup) | 로그인이 되면 끝 |

<br/>

- macOS는 `xcode-select --install`로 Git이 함께 깔립니다.
- Windows는 Docker Desktop 설치 중 WSL2를 함께 켭니다.

</Slide>

### 첫 명령: 컨테이너 띄우기

- 실행

```sh
git clone https://github.com/lec-algorithm/algorithm-code.git
cd algorithm-code
docker compose up -d
```

- 결과

```console
[+] Running 2/2
 ✔ Network algorithm-code_default  Created    0.0s
 ✔ Container algorithm-code-lab-1  Started    0.3s
```

처음 한 번은 이미지를 받느라 몇 분 걸립니다. 이후에는 몇 초면 뜹니다.  
**이후 모든 `docker compose` 명령은 이 `algorithm-code` 폴더에서 칩니다.**

</Slide>

<Slide class="compact">

### 컨테이너 안에 무엇이 있나
::sub[컴파일러와 Python은 설치하지 않습니다]

- 실행

```sh
docker compose exec lab gcc --version | head -1
docker compose exec lab python3 --version
```

- 결과

```console
gcc (Debian 14.2.0-19) 14.2.0
Python 3.13.5
```

<br/>

설치 방법이 운영체제마다 갈리는 것을 없애기 위해서입니다.  
여러분의 노트북이 무엇이든 컨테이너 안은 똑같습니다.

</Slide>

<Slide class="compact">

### 컨테이너 안으로 들어가기

- 실행

```sh
docker compose exec lab bash
```

- 결과

```console
root@8f3c1d2a4b5e:/work# ls
Dockerfile  compose.yml  topic-01-intro-search  ...
```

프롬프트가 바뀌면 그 다음부터는 컨테이너 안입니다.  
저장소 폴더가 `/work`에 그대로 연결되어 있습니다.

</Slide>

<Slide class="compact">

### 예제 하나 돌려보기

- 실행

```sh
cd topic-01-intro-search/01_sequential_search
gcc -o sequentialSearch sequentialSearch.c && ./sequentialSearch
python3 sequential_search.py
```

- 결과

```console
n = 15, key = 51
index = 6, comparisons = 7
```

두 구현이 같은 결과를 내면 준비가 끝난 것입니다.  
코드는 호스트 편집기로 고치고, 실행만 컨테이너에서 합니다.

</Slide>
