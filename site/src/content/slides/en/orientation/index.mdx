## What this course does
::sub[From sorting and divide-and-conquer to graphs and dynamic programming]

- Computer algorithms and **the logic behind them**
- A range of sorting algorithms, divide-and-conquer, dynamic programming
- **How to judge** the complexity of an algorithm

</Slide>

<Slide>

## How it runs
::sub[One pseudocode, two implementations]

- Every algorithm is defined in **pseudocode** first.
  - The C and Python versions are transcriptions of it.
- This is not a course about a language.
  - It is about seeing one procedure take two shapes.
- The runtime is **pinned in a container**.
  - Git and Docker are the only installs, and Codespaces removes even those.
- Lecture 50% · lab work 50%

</Slide>

### What is in the container
::sub[You do not install a compiler or Python]

- Run

```sh
gcc --version | head -1
python3 --version
```

- Output

```console
gcc (Debian 14.2.0-19) 14.2.0
Python 3.13.5
```

<br/>

This removes the differences between operating systems.  
Whatever your laptop is, the inside of the container is identical.

</Slide>

<Slide class="compact">

### Run one example

- Run

```sh
cd src/topic-01-intro-search/01_sequential_search
gcc -o sequentialSearch.out sequentialSearch.c && ./sequentialSearch.out
python3 sequential_search.py
```

- Output

```console
n = 15, key = 51
index = 6, comparisons = 7
```

When both implementations print the same thing, you are set up.

</Slide>

<Slide class="compact">

### Running it locally
::sub[On your own machine instead of Codespaces]

- Run

```sh
git clone https://github.com/lec-algorithm/algorithm-code.git
cd algorithm-code
docker compose up -d
docker compose exec lab bash
```

- Output

```console
root@d38ddee8c2a8:/work#
```

<br/>

Once the prompt changes, everything is **the same as above**.  
Codespaces uses the same `compose.yml`.

</Slide>

<Slide class="compact">

### New topics, and opening it in VS Code
::sub[Locally you get the same environment as Codespaces]

- Run

```sh
git pull        # take the topics added since
code .          # open this folder in VS Code
```

When VS Code offers **Reopen in Container**, take it.  
If it does not, use the command palette: **Dev Containers: Reopen in Container**

<br/>

It reads the same `.devcontainer` configuration, so the compiler, Python and
the extensions are already there.  
The ▶ button and `F5` behave exactly as they do in Codespaces.

</Slide>

### Attendance is counted in class-hour units
::sub[Up to 6 units of absence for the semester]

- A class-hour unit is how attendance is counted: a 1-hour class is 1 unit, a 2-hour class is 2 units.
  - Wed period 5 (1 unit) + Fri periods 5\~6 (2 units) = 3 units a week
- You may miss up to **6 units** total over the semester.
- If LearnUs fails to recognize your attendance, email a photo taken in the classroom to tkl@yonsei.ac.kr.

</Slide>
