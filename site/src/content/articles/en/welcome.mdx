This is the course site for **Advanced Algorithms**.
Course material goes here; LearnUs carries the administrative notices.

## What is where \{#where}

| Menu | Holds |
| --- | --- |
| [Lectures](/course/) | Lecture notes by topic, written to be read rather than presented |
| [Slides](/slides/) | The decks used in class, viewable straight in the browser |
| [Posts](/article/) | Notices, assignment briefs, setup guides |
| [Lab environment](/categories/env/) | The languages and tools the course uses |
| [Glossary](/glossary/) | Short definitions of the terms that appear in the text |

## The code lives elsewhere \{#repos}

This site holds only what you read. The code that runs is separate.

- [algorithm-code](https://github.com/lec-algorithm/algorithm-code): pseudocode with C and Python implementations, by topic. A template repository, so you make your own copy and work there
- [algorithm-viz](https://github.com/lec-algorithm/algorithm-viz): algorithm visualizations. The output is embedded in the slides

Start with [Setting up the lab](/article/setup-guide/).

## Material arrives during the semester \{#schedule}

Each topic goes up before the week it is taught. Topics still in preparation
show only their title and an outline of what they will cover.
