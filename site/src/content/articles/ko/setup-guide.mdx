수업에서 쓰는 것은 셋뿐입니다. **C 컴파일러**, **Python**, **Git**.
전부 무료이고, 설치까지 30분이면 끝납니다.

## 1. C 컴파일러 \{#c}

실습 코드는 표준 C로 작성되어 있어 별도 라이브러리가 필요 없습니다.

| 운영체제 | 준비 방법 |
| --- | --- |
| macOS | 터미널에서 `xcode-select --install` |
| Windows | [MSYS2](https://www.msys2.org/) 설치 후 `pacman -S mingw-w64-ucrt-x86_64-gcc` |
| Linux | `sudo apt install build-essential` |

확인:

```sh
gcc --version
```

## 2. Python \{#python}

3.11 이상이면 됩니다. [python.org](https://www.python.org/downloads/)에서 받거나
운영체제의 패키지 관리자를 씁니다.

```sh
python3 --version
```

## 3. Git \{#git}

개인프로젝트는 GitHub 저장소 제출이 필수입니다. 학기 초에 계정을 만들어
두세요.

```sh
git --version
git config --global user.name "본인 이름"
git config --global user.email "본인 이메일"
```

## 4. 실습 코드 받기 \{#clone}

```sh
git clone https://github.com/lec-algorithm/algorithm-code.git
cd algorithm-code
```

주제별로 폴더가 나뉘고, 한 예제 안에 의사코드와 두 구현이 함께 있습니다.

```plaintext
topic-01-intro-search/
└── 01_sequential_search/
    ├── sequentialSearch.pseudo   # 기준이 되는 절차
    ├── sequentialSearch.c        # C 구현
    └── sequential_search.py      # Python 구현
```

## 5. 첫 예제 돌려보기 \{#run}

```sh
cd topic-01-intro-search/01_sequential_search
gcc -o sequentialSearch sequentialSearch.c && ./sequentialSearch
python3 sequential_search.py
```

두 명령이 같은 결과를 내면 준비가 끝난 것입니다.

## 자주 막히는 곳 \{#troubleshooting}

| 증상 | 확인할 것 |
| --- | --- |
| `gcc: command not found` | 1번을 다시 확인하세요. Windows는 MSYS2 터미널에서 실행해야 합니다 |
| `python: command not found` | `python` 대신 `python3`을 쓰세요 |
| 한글이 깨져 보임 | 터미널 인코딩을 UTF-8로 바꿉니다 |
| `git clone` 권한 오류 | 저장소 주소를 다시 확인하세요. 공개 저장소라 로그인 없이 받을 수 있습니다 |
