# docs

저장소 운영·개발 규칙 문서와 강의 기획 자료

## 규칙 문서

- [writing-rules.md](writing-rules.md): 콘텐츠·문서 작성 규칙 (한글 문장
  스타일, 마크다운 이스케이프(표 파이프·물결표), 소프트 줄바꿈, 이 과정 고유의
  표기, 슬라이드 규칙)
- [documentation-rules.md](documentation-rules.md): 문서의 위치·파일명·구성
  규칙과 다른 저장소와의 역할 분담
- [git-workflow.md](git-workflow.md): git flow 브랜치 모델과 커밋 규칙
  (커밋하면서 진행, 커밋 전 검증, 메시지 스타일, 릴리스 절차)
- [deployment.md](deployment.md): GitHub Pages 공개 배포 (워크플로 동작,
  저장소 설정, base 경로)

## 강의 기획

- [syllabus.md](syllabus.md): 2026학년도 2학기 수업계획서 원문.
  **학교 원본을 그대로 옮긴 파일**이라 손대지 않고, 원본이 갱신되면 통째로
  교체한다. 작성 규칙과 스타일 검사에서도 제외한다
- [source-materials.md](source-materials.md): 예전 Keynote 덱 13개의 내용
  분석과 새 주제 대응표. 원본이 참조하던 코드 구조도 여기에 정리했다
- [course-plan.md](course-plan.md): 주제 14개 + 보너스 1개로의 재편 계획.
  주차별 진도, 평가 일정, 콘텐츠 파일 구조와 프론트매터 규약, 작업 순서
- [repositories.md](repositories.md): 조직의 저장소 세 개(`lecture`,
  `algorithm-code`, `algorithm-viz`)의 역할 분담

## 주제별 강의 문서

주제별 교안은 강의 사이트의 course 문서가 단일 원본이다.
`site/src/content/courses/ko/`에 둔다. 예를 들어 주제 01은
`topic-01-intro-search.mdx`다. 슬라이드도 이 문서를 토대로 만든다.
