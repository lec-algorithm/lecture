## 원본이 참조하던 코드

슬라이드 안에 `lec02/01_selection_sort/selectionSort.c` 같은 경로가 그대로
찍혀 있다. 즉 원본에도 짝이 되는 코드 저장소가 있었고, 구성은 아래와 같았다.

- 폴더: `lecNN/<번호>_<주제>/`
- 파일: `<algorithm>.pseudo`, `<algorithm>.c`, 일부 `*_animation.py`
- 확인된 C 파일 참조 114건, Python 참조 10건 (대부분 애니메이션 생성용)

새 구성에서는 이 구조를 물려받되 셋으로 나눈다.

- 폴더 이름을 `src/topic-NN-<슬러그>`로 바꾸고 주제 번호 체계에 맞춘다.
- C 옆에 같은 알고리즘의 Python 구현을 나란히 둔다.
- 애니메이션 생성 스크립트는 `algorithm-viz`로 분리한다.

상세는 [repositories.md](repositories.md) 참고

## 변환할 때 주의할 것

- **쪽수는 슬라이드 수가 아니다.** 원본은 한 단계를 한 장씩 넘기는 방식이라
  퀵 정렬 한 예제가 100쪽을 넘는다. 웹 덱에서 같은 방식으로 옮기면 안 된다.
  단계 전개는 표·다이어그램 한 장으로 접고, 움직임이 필요하면
  `algorithm-viz` 산출물을 임베드한다.
- **텍스트가 없는 쪽이 있다.** 이미지 한 장만 있는 슬라이드는 PDF에서 글자가
  나오지 않는다. 원본 PDF를 직접 열어 확인해야 한다.
- **한국어와 영어가 섞여 있다.** 제목은 한글 뒤에 영어를 병기하는 형태가
  많다. 새 자료의 표기 규칙은 [writing-rules.md](writing-rules.md)를 따른다.
